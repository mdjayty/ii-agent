# Travel Agent - Research Approach & Methodology

**Last Updated:** 2025-02-09
**Version:** 1

This document defines the travel agent's standard approach for planning trips. It is read before every research session and updated with improvements after each session.

---

## Core Research Philosophy

1. **Thorough before decisive** - Gather multiple data points before making recommendations
2. **Source everything** - Every fact, price, and recommendation must have a source URL
3. **Compare systematically** - Use standardized comparison matrices for hotels, flights, activities
4. **Budget-aware** - Always track costs against the trip budget
5. **Family-first** - Prioritize family-friendly options (rooms, activities, pacing)

---

## Standard Research Workflow

### Step 1: Understand Requirements
- Read the current itinerary and budget files
- Read memory files for learned patterns
- Identify what specifically needs to be researched
- Note any constraints (budget, dates, preferences)

### Step 2: Broad Search
- Search 3-5 sources for initial options
- Cast a wide net before narrowing down
- Note price ranges and availability patterns

### Step 3: Deep Dive
- Visit official websites for top candidates
- Cross-reference prices across booking platforms
- Check reviews on multiple sites (TripAdvisor, Google, Booking.com)
- Note cancellation policies and family-specific features

### Step 4: Comparison & Recommendation
- Create standardized comparison table
- Score options on key criteria
- Provide clear recommendation with reasoning
- Note alternatives and trade-offs

### Step 5: Document & Update
- Save research to appropriate subfolder
- Update itinerary/budget if applicable
- Follow versioning protocol for existing files
- Update memory files with new patterns learned

## Budget Tracking Rules

1. All costs in USD unless noted
2. Convert using current exchange rates (note the rate used)
3. Round up for safety margin
4. Always calculate per-person AND family total
5. Track against overall budget with running remaining balance
6. Flag when any category exceeds initial estimate by >20%
